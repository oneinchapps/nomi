Wie können wir helfen?

Die häufigsten Fragen zu nomi – und wie du uns erreichst, wenn etwas klemmt.

Kontakt

Schreib uns an [E-Mail-Adresse]. Am besten mit iPhone- oder iPad-Modell und einer kurzen Beschreibung, was passiert ist – wir melden uns.

Anmelden

Wie melde ich mich an?

Mit deiner E-Mail-Adresse. nomi schickt dir einen 6-stelligen Code, den gibst du in der App ein. Ein Passwort brauchst du nicht.

Der Code kommt nicht an.

Schau im Spam-Ordner nach einer Mail von code@mail.oneinchapps.com. Einen neuen Code kannst du nach einer Minute anfordern. Ein Code gilt eine Stunde.

Zu zweit

Wie kommt die zweite Person dazu?

Wer den Haushalt angelegt hat, findet unter „Heute“ eine Einladung mit Code und kann sie per WhatsApp oder Nachricht verschicken. Die zweite Person tippt in nomi auf „Ich habe eine Einladung“ und gibt den Code ein – ganz ohne E-Mail. Ein Code gilt sieben Tage.

Ich habe ein neues Handy und mich ohne E-Mail angemeldet.

Die andere Person im Haushalt öffnet ihr Profil (oben rechts) und tippt auf „Neues Handy? Code für … schicken“. Mit diesem Code kommst du auf dem neuen Handy über „Ich habe eine Einladung“ wieder in dein Konto.

Rezepte

Wie kommen Rezepte in nomi?

Teile einen Link aus Safari, Instagram oder TikTok an nomi, füge ihn in der App ein oder fotografiere eine Seite aus dem Kochbuch. nomi liest Zutaten und Schritte aus; du kannst danach alles bearbeiten.

Ein Link funktioniert nicht.

Manche Seiten sperren automatische Abrufe. Dann hilft ein Foto oder Screenshot des Rezepts.

Kochen

Der Timer klingelt nicht.

nomi stellt Timer als Wecker, damit sie auch bei stummem iPhone klingeln. Dafür braucht nomi deine Erlaubnis: Einstellungen → nomi → Wecker. Ohne Erlaubnis klingelt nomi nur, solange die App offen ist.

Konto und Daten

Wie lösche ich mein Konto?

In nomi oben rechts auf dein Profil tippen und „Konto löschen“ wählen. Dabei verschwinden dein Konto, dein Profilfoto und deine Nachrichten an nomi. Bist du allein im Haushalt, wird der ganze Haushalt mit Rezepten, Plänen und Listen gelöscht.

Was passiert mit meinen Daten?

Das steht ausführlich in der Datenschutzerklärung. Kurz: kein Tracking, keine Werbung, Speicherung in der EU.
